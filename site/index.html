Architecture




1 · Data
NSL-KDD parser (43 columns → 5 classes) with a labelled synthetic fallback.


2 · Pipeline
One-hot encoding + RandomForest in a single scikit-learn pipeline.


3 · Serving
FastAPI service with API-key auth, batch limits and SHA-256 model integrity check.


4 · SOC
ECS-style JSON alerts for Wazuh, Splunk and Elastic; Streamlit analyst dashboard.




curl -X POST $HOST/predict -H "X-API-Key: $KEY" -H "Content-Type: application/json" \
  -d '{"features": {"src_bytes": 500, "count": 10, "serror_rate": 0.0}}'


Limitations: NSL-KDD is a 2009-era benchmark; validate on your own labelled traffic before production use. Input is pre-computed flow features, not raw packets.
